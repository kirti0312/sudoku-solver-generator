# Sudoku Solver & Generator

A modern Sudoku web application featuring puzzle generation and solving using Java backtracking algorithms with an interactive frontend built using HTML, CSS and JavaScript.

## Features
- Generate random Sudoku puzzles
- Solve Sudoku using backtracking algorithm
- Interactive responsive UI
- Dark-themed modern design
- Real-time puzzle interaction

## Technologies Used
- Java
- HTML
- CSS
- JavaScript
- Backtracking Algorithm
- Recursion

## Project Structure

```text
sudoku-dsa-project/
│
├── src/
│   ├── App.java

│   └── SudokuSolver.java
│
├── web/
│   ├── index.html
│   ├── style.css
│   └── script.js
```

## How It Works
The frontend interacts with Java-based Sudoku generation and solving logic through a lightweight HTTP server. The Sudoku solver uses recursion and backtracking to efficiently solve puzzles.

## Run Locally

1. Clone the repository
2. Compile Java files
3. Run App.java
4. Open localhost in browser
