How the Backtracking Algorithm Works

Backtracking is an algorithmic-technique for solving problems recursively by trying to build a solution incrementally, one piece at a time, removing those solutions that fail to satisfy the constraints of the problem at any point in time.

1

Find Empty

Scan the grid from top-left to find the first unassigned cell.

2

Try Numbers

Iterate digits 1 to 9. Check row, column, and 3x3 box constraints.

3

Recurse

If valid, assign the number and recursively try to solve the rest.

4

Backtrack

If grid cannot be completed, reset cell to empty (0) and backtrack to try next number.

Built with Java HTTP Server, Native Backtracking Algorithm, and Glassmorphic Vanilla CSS/JS
